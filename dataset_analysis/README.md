# CausalOps Dataset Analysis

This directory contains analytical tools and findings for inspecting experiments generated by **Dataset Generator v1**.

## Contents

- **`analyze.py`**: Automated analysis script that processes raw JSON artifacts across `dataset/experiments/E001` through `E010`, computes empirical telemetry deltas, analyzes temporal precedence, categorizes heuristic RCA failure modes, and renders the markdown diagnostic report.
- **`report.md`**: Complete generated empirical analysis report answering all verification tasks (signal quality, temporal resolution, failure categorization, fault class comparisons, dataset quality criteria, and future experiment matrix).

## How to Run

To execute the dataset analysis and regenerate `report.md`:

```bash
python3 dataset_analysis/analyze.py
```

The script inspects:
- `manifest.json`: Injected fault target (ground truth) vs detected RCA candidate.
- `metrics.json`: Raw telemetry samples across the observation window.
- `incidents.json`: Detected incident IDs and metadata.
- `rca.json`: Full candidate ranking and signal breakdowns (`anomaly`, `temporalPrecedence`, `dependency`, `propagationConsistency`, `metricCorrelation`).
- `topology.json`: Microservice call graph and causal paths.
